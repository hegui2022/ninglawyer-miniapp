## 🚀 部署说明

### 1. 环境配置

创建 `.env` 文件：

```env
API_HOST=0.0.0.0
API_PORT=8080
DB_HOST=localhost
DB_PORT=5432
DB_NAME=ninglawyer
MODEL_NAME=doubao-seed-1-6-251015
# ... 其他配置
```

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 初始化数据库

```bash
createdb ninglawyer
```

### 4. 启动服务

```bash
python src/main.py
```

### 5. 小程序部署

1. 打开微信开发者工具
2. 导入小程序项目
3. 配置 AppID
4. 上传代码
5. 提交审核
6. 发布上线

详细部署步骤请参考 [DEPLOYMENT.md](./DEPLOYMENT.md)
