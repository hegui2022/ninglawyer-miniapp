## 🛠️ 开发配置

### 1. 配置 AppID

在每个小程序目录下修改 `project.config.json`，填入你的 AppID：

```json
{
  "appid": "你的小程序AppID"
}
```

如果没有 AppID，可以使用测试号：
- 登录微信开发者工具
- 选择"测试号"
- 获取测试号 AppID

### 2. 配置 API 地址

修改每个小程序的 `app.js` 文件中的 API 地址：

```javascript
globalData: {
  config: {
    apiUrl: 'http://localhost:5000/api',  // 开发环境
    baseUrl: 'http://localhost:5000'
  }
}
```

**生产环境配置**：
```javascript
globalData: {
  config: {
    apiUrl: 'https://your-api-domain.com/api',  // 生产环境
    baseUrl: 'https://your-api-domain.com'
  }
}
```

### 3. 配置服务器域名（生产环境）

登录微信公众平台：
1. 进入"开发" -> "开发管理"
2. 选择"开发设置"
3. 配置"服务器域名"
   - request合法域名：`https://your-api-domain.com`
   - uploadFile合法域名：`https://your-api-domain.com`
   - downloadFile合法域名：`https://your-api-domain.com`

## 🎯 运行步骤

### 步骤1: 启动后端服务

```bash
cd /workspace/projects/ninglawyer-miniapp

# 使用 Docker Compose 启动
docker-compose up -d

# 或使用启动脚本
./scripts/start.sh
```

### 步骤2: 打开微信开发者工具

1. 启动微信开发者工具
2. 选择"导入项目"
3. 选择小程序目录（例如：`legal-instructor`）
4. 填写 AppID（可以使用测试号）
5. 点击"导入"

### 步骤3: 编译运行

1. 微信开发者工具会自动编译
2. 点击"编译"按钮
3. 在模拟器中查看效果

### 步骤4: 真机调试

1. 点击"真机调试"按钮
2. 使用微信扫描二维码
3. 在手机上查看效果

## 🔧 常见问题

### 1. 网络请求失败

**原因**：未配置服务器域名或使用本地IP

**解决方案**：
- 开发环境：在微信开发者工具中勾选"不校验合法域名"
- 生产环境：在微信公众平台配置服务器域名

### 2. 页面找不到

**原因**：`app.json` 中的页面路径配置错误

**解决方案**：
- 检查 `app.json` 中的 `pages` 配置
- 确保页面文件存在（js, wxml, wxss, json）

### 3. 图片加载失败

**原因**：图片路径错误或图片不存在

**解决方案**：
- 检查图片路径是否正确
- 确保图片文件存在于项目目录中
- 使用网络图片时确保网络正常

### 4. 登录失败

**原因**：后端服务未启动或配置错误

**解决方案**：
- 确保后端服务已启动
- 检查 API 地址配置
- 查看控制台错误信息

## 📝 开发规范

### 代码规范
- 使用微信小程序官方命名规范
- 代码缩进使用 2 个空格
- 使用语义化的变量和函数名
- 添加必要的注释

### 样式规范
- 使用 rpx 单位（自适应）
- 遵循微信设计规范
- 主色调：`#07C160`
- 圆角：`16rpx` 或 `48rpx`

### 组件规范
- 组件名称使用小写字母和连字符
- 组件文件放在 `components/` 目录
- 在 `app.json` 或页面的 `json` 文件中注册

## 🎨 设计规范

### 色彩
- 主色：`#07C160` (绿色)
- 辅助色：`#FF9800` (橙色)
- 警示色：`#F44336` (红色)
- 信息色：`#2196F3` (蓝色)
- 背景色：`#F5F5F5` (灰色)

### 字体
- 标题：`36rpx` - `48rpx`
- 正文：`28rpx` - `32rpx`
- 辅助：`24rpx` - `26rpx`

### 间距
- 小间距：`12rpx`
- 中间距：`24rpx`
- 大间距：`32rpx`

## 🚢 部署流程

### 1. 上传代码

在微信开发者工具中：
1. 点击"上传"按钮
2. 填写版本号和项目备注
3. 点击"上传"

### 2. 提交审核

在微信公众平台：
1. 进入"版本管理"
2. 选择"开发版本"
3. 点击"提交审核"
4. 填写审核信息

### 3. 发布

审核通过后：
1. 进入"版本管理"
2. 选择"审核版本"
3. 点击"发布"
