## 🚀 如何运行

### 步骤 1: 启动后端服务

```bash
cd /workspace/projects/ninglawyer-miniapp
docker-compose up -d
```

### 步骤 2: 打开微信开发者工具

1. 启动微信开发者工具
2. 选择"导入项目"
3. 选择小程序目录（例如：`legal-instructor`）
4. AppID 使用"测试号"（touristappid）
5. 点击"导入"

### 步骤 3: 配置开发环境

在微信开发者工具中：
1. 点击右上角"详情"
2. 勾选"不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书"

### 步骤 4: 编译运行

1. 点击"编译"按钮
2. 在模拟器中查看效果
