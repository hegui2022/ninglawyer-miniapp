# 自动同步工具使用指南

## 📋 概述

本工具套件为您提供多种方式来**自动同步 GitHub 代码**并**实时查看我的更新**，让您在本地几乎零延迟地获取最新代码。

---

## 🚀 快速开始

### 方法 1：一键启动（推荐）

双击运行 `start.bat`，选择您需要的功能：

```
[1] 启动实时监控（每 30 秒检查一次）
[2] 立即同步最新代码
[3] 查看最近提交记录
[4] 启动微信开发者工具
[0] 退出
```

---

## 📦 工具说明

### 1. **sync.bat** - 手动同步工具

**功能**：手动拉取最新代码

**使用方式**：
```batch
双击运行 sync.bat
```

**效果**：
- 检查 GitHub 是否有新提交
- 如果有更新，自动拉取到本地
- 显示最新提交信息
- 提示刷新微信开发者工具

---

### 2. **monitor.bat** - 实时监控工具（Windows 批处理版）

**功能**：每 30 秒自动检查一次更新

**使用方式**：
```batch
双击运行 monitor.bat
```

**效果**：
- 后台运行，不影响您的工作
- 发现更新时会在控制台显示通知
- 提示您运行 `sync.bat` 进行同步

**停止**：按 `Ctrl + C`

---

### 3. **monitor.py** - 实时监控工具（Python 高级版）

**功能**：更智能的监控，支持更多配置

**使用方式**：
```batch
python monitor.py
```

**配置**：
编辑 `monitor.py` 文件中的 `CONFIG` 字典：

```python
CONFIG = {
    'project_path': 'C:\\Users\\Administrator\\ninglawyer-miniapp',  # 项目路径
    'monitor_interval': 30,  # 监控间隔（秒）
    'auto_sync': False,  # 是否自动同步（建议设为 False）
}
```

**特点**：
- 显示更详细的提交信息
- 支持自动同步（可选）
- 更友好的控制台输出

---

### 4. **auto-sync.bat** - 智能同步工具

**功能**：自动同步并尝试刷新微信开发者工具

**使用方式**：
```batch
双击运行 auto-sync.bat
```

**效果**：
- 自动拉取代码
- 尝试刷新所有小程序项目（需要配置微信开发者工具路径）

**注意**：需要在 `auto-sync.bat` 中配置正确的微信开发者工具路径

---

### 5. **post-merge** - Git 钩子（macOS/Linux）

**功能**：每次执行 `git pull` 后自动提醒刷新

**配置方式**：
```bash
# 确保 hook 文件有执行权限
chmod +x .git/hooks/post-merge
```

## ⚙️ 配置说明

### 修改项目路径

所有脚本默认使用 `C:\Users\Administrator\ninglawyer-miniapp`，请根据您的实际情况修改：

**Windows 脚本**（.bat 文件）：
```batch
set PROJECT_DIR=您的项目路径
```

**Python 脚本**（monitor.py）：
```python
'project_path': '您的项目路径',
```

### 修改监控间隔

在 `monitor.py` 中修改：
```python
'monitor_interval': 30,  # 改为您想要的秒数
```

### 配置微信开发者工具路径

在 `auto-sync.bat` 中修改：
```batch
set WECHAT_TOOLS_EXE="您的微信开发者工具路径\cli.bat"
```

**Windows 默认路径**：
```
C:\Program Files (x86)\Tencent\微信web开发者工具\cli.bat
```

## 💡 使用建议

### 开发工作流

1. **启动监控**：双击运行 `start.bat`，选择 `[1] 启动实时监控`
2. **日常开发**：在微信开发者工具中正常开发
3. **发现更新**：监控工具会在控制台提示发现更新
4. **同步代码**：
   - 选择 `[2] 立即同步最新代码`
   - 或按 `Ctrl+C` 停止监控，运行 `sync.bat`
5. **刷新项目**：在微信开发者工具中按 `Ctrl+S` 重新编译

### 提高效率的技巧

1. **分屏显示**：将监控窗口放在屏幕一侧，不影响开发
2. **自动刷新**：修改 `monitor.py` 设置 `'auto_sync': True`，实现全自动
3. **快捷键**：为 `sync.bat` 创建桌面快捷键，一键同步

## 🔧 故障排除

### 问题 1：提示"无法找到 git"

**解决方案**：
```batch
# 检查 git 是否安装
git --version

# 如果未安装，请从以下地址下载安装
# https://git-scm.com/download/win
```

### 问题 2：无法连接到 GitHub

**解决方案**：
```batch
# 检查网络连接
ping github.com

# 配置 Git 代理（如果需要）
git config --global http.proxy http://代理地址:端口
git config --global https.proxy https://代理地址:端口
```

### 问题 3：微信开发者工具路径错误

**解决方案**：
1. 找到微信开发者工具的安装路径
2. 复制 `cli.bat` 文件的完整路径
3. 在 `auto-sync.bat` 中修改 `WECHAT_TOOLS_EXE` 变量

### 问题 4：监控工具不提示更新

**解决方案**：
1. 检查项目路径是否正确
2. 检查 Git 远程仓库地址是否正确
3. 手动运行 `git fetch` 测试连接
4. 查看监控工具的错误信息

3. 项目路径是否正确

## 🎯 最佳实践

1. **开发前同步**：每天开始开发前，先运行一次 `sync.bat`
2. **提交前同步**：在推送代码前，确保已拉取最新代码
3. **定期监控**：启动 `monitor.py` 或 `monitor.bat`，实时了解更新
4. **分支管理**：在开发分支上工作，避免直接修改 main 分支
