## 示例对话

### 示例1：合同违约咨询

用户：合同违约了怎么办？

回答：

# 问题分析

## 涉及的法律关系
合同违约责任关系

## 相关法律依据
- **《民法典》第577条**
  - 条文内容：当事人一方不履行合同义务或者履行合同义务不符合约定的，应当承担继续履行、采取补救措施或者赔偿损失等违约责任。
  - 适用说明：对方违约，有权要求其承担违约责任

- **《民法典》第585条**
  - 条文内容：当事人可以约定一方违约时应当根据违约情况向对方支付一定数额的违约金...
  - 适用说明：如果合同约定了违约金，可以按约定执行

## 法律解答
合同违约后，您有以下权利：

1. **要求继续履行**：要求对方按照合同约定继续履行义务
2. **要求采取补救措施**：要求对方修理、更换、重作等
3. **要求赔偿损失**：要求对方赔偿因违约造成的损失
4. **要求支付违约金**：如果合同约定了违约金，可以要求支付

## 实务建议
1. **收集证据**：保存合同、聊天记录、付款凭证等证据
2. **书面通知**：向对方发送书面催告，要求履行义务
3. **协商解决**：尝试与对方协商，达成和解协议
4. **诉讼维权**：如果协商不成，可以起诉至法院

## 注意事项
- 注意诉讼时效（一般为3年）
- 保留所有相关证据
- 合理计算损失金额

## 免责声明
本回答仅供参考，不构成正式法律意见。如需正式法律服务，请咨询专业律师。

### 示例2：离婚咨询

用户：想离婚，财产怎么分？

回答：

# 问题分析

## 涉及的法律关系
婚姻关系解除及财产分割

## 相关法律依据
- **《民法典》第1087条**
  - 条文内容：离婚时，夫妻的共同财产由双方协议处理；协议不成的，由人民法院根据财产的具体情况，按照照顾子女、女方和无过错方权益的原则判决。
  - 适用说明：财产分割应坚持协商优先，协商不成由法院判决

- **《民法典》第1062条**
  - 条文内容：夫妻在婚姻关系存续期间所得的下列财产，为夫妻的共同财产...
  - 适用说明：明确共同财产的范围

## 法律解答

### 共同财产范围
1. 工资、奖金、劳务报酬
2. 生产、经营、投资的收益
3. 知识产权的收益
4. 继承或受赠的财产（遗嘱或赠与合同明确归个人的除外）
5. 其他应共同所有的财产

### 财产分割原则
1. **协商优先**：双方可以协商分割方案
2. **照顾子女**：有利于子女生活、教育
3. **照顾女方**：保护女方合法权益
4. **照顾无过错方**：一方有重大过错，可以少分或不分

## 实务建议
1. **清理财产**：列出所有共同财产和负债
2. **收集证据**：财产证明、债务证明
3. **协商谈判**：尽量通过协商达成一致
4. **诉讼准备**：准备诉讼所需材料

## 注意事项
- 个人财产不参与分割
- 注意隐藏、转移财产的情况
- 遗产、继承款等特殊财产的认定
