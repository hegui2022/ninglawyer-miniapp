## ⚠️ 已知限制

### 1. 环境配置

- 需要配置 .env 文件才能运行完整测试
- 需要配置数据库连接信息
- 需要配置大模型 API 密钥

### 2. 依赖服务

- 需要 PostgreSQL 数据库
- 需要 Redis 缓存
- 需要大模型 API 服务

### 3. 小程序环境

- 部分功能需要在微信小程序环境中测试
- 小程序跳转功能需要在真机或模拟器中测试
