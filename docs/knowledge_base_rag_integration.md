## 🧪 测试效果

### 测试场景 1：劳动合同丢失

**用户问题**：
```
劳动合同丢了怎么办？能不能证明劳动关系？
```

**Agent 行为**：
1. ✅ 自动调用 `search_legal_knowledge` 查询知识库
2. ✅ 获取知识库内容："劳动合同丢了，能证明劳动关系吗？"
3. ✅ 获取解答："可以。除了劳动合同，还可以提供工资条、考勤记录、工牌、工作证、与用人单位的聊天记录等证据来证明劳动关系。"
4. ✅ 用大白话解释："这事儿好办，就算合同丢了也能证明劳动关系。你平时发工资的银行流水、单位给你打的工资条，还有考勤记录、工牌、工作证这些都能当证据用。"
5. ✅ 生活化比喻："就像你去超市买东西，没拿购物小票，但付款记录、超市的监控都能证明你买过东西。"
6. ✅ 精准追问："你手里现在有哪些能证明你在公司上班的东西？"

### 测试场景 2：劳动仲裁时长和投诉地点

**用户问题**：
```
如果老板不给我工资，劳动仲裁要多久？还有，去哪里投诉？
```

**Agent 行为**：
1. ✅ 自动调用 `search_legal_knowledge` 查询知识库
2. ✅ 获取知识库内容：
   - "劳动仲裁委员会应当自受理仲裁申请之日起四十五日内结束仲裁案情。"
   - "可以先向当地劳动监察大队投诉，劳动监察大队会责令用人单位支付工资。"
3. ✅ 用大白话解释："先去公司所在地的劳动监察大队投诉...要是协调不成，再去劳动仲裁委员会申请仲裁，这个是免费的。"
4. ✅ 明确时间："劳动仲裁的话，从受理到出结果一般是45天，要是案情复杂最多再延15天，也就是两个月之内肯定有结果。"
5. ✅ 给出建议："你手里现在有劳动合同或者工资条、考勤记录这些东西吗？先把证据都整理好。"

## 🔧 技术实现

### 知识库RAG流程
```
1. 用户提问
   ↓
2. Agent识别为法律问题
   ↓
3. 调用 search_legal_knowledge 工具
   ↓
4. 知识库向量搜索
   ↓
5. 返回Top 3相关内容
   ↓
6. Agent基于知识库内容生成回复
   ↓
7. 用大白话解释给用户
```
