# 自动化工具快速开始指南

## 🚀 3 步快速开始

### 第 1 步：配置路径（首次使用必须）

双击运行 `config-wizard.bat`，按照提示配置：

```
========================================
宁律师小程序 - 自动化工具配置向导
========================================

当前配置：

项目路径: C:\Users\Administrator\ninglawyer-miniapp
微信开发者工具路径: C:\Program Files (x86)\Tencent\微信web开发者工具\cli.bat

是否需要修改配置？
[Y] 是，修改配置
[N] 否，使用当前配置
```

**如果需要修改**：

1. 输入 `Y`，按回车
2. 输入项目路径（例如：`C:\Users\YourName\Documents\ninglawyer-miniapp`）
3. 输入微信开发者工具路径（例如：`C:\Program Files (x86)\Tencent\微信web开发者工具\cli.bat`）
4. 输入监控间隔（例如：`30` 秒）

**验证配置**：

```
========================================
验证配置
========================================

[✓] 项目路径存在: C:\Users\YourName\Documents\ninglawyer-miniapp
[✓] 微信开发者工具路径存在
```

---

### 第 2 步：启动自动化工具

双击运行 `start.bat`，您会看到：

```
========================================

========================================

[1] 启动实时监控（每 30 秒检查一次）
[2] 立即同步最新代码
[3] 查看最近提交记录
[4] 打开微信开发者工具
[5] 快速提交代码
[6] 配置路径
[0] 退出

请输入选项 (0-6):
```

**推荐：选择 [1] 启动实时监控**

```
========================================
实时监控
========================================

[提示] 启动实时监控...
[提示] 按 Ctrl+C 停止监控

2024-01-29 10:00:00 - 检查更新...
2024-01-29 10:00:00 - [✓] 已是最新版本
2024-01-29 10:00:30 - 检查更新...
2024-01-29 10:00:30 - [✓] 已是最新版本
```

---

### 第 3 步：开始开发

保持实时监控开启，开始开发：

1. **修改代码** - 在微信开发者工具中修改小程序代码
2. **提交代码** - 运行 `start.bat` → 选择 [5] 快速提交
3. **自动同步** - 其他设备会自动检测到新代码并拉取
4. **自动刷新** - 微信开发者工具会自动刷新

## ⚙️ 配置文件

所有配置都存储在 `sync-config.ini` 文件中：

```ini
[General]
# 项目路径（必须修改）
PROJECT_PATH=C:\Users\YourName\Documents\ninglawyer-miniapp

# 监控间隔（秒），默认 30 秒
MONITOR_INTERVAL=30

[WeChatDevTools]
# 微信开发者工具路径（必须修改）
WIN_PATH=C:\Program Files (x86)\Tencent\微信web开发者工具\cli.bat

[Projects]
# 需要刷新的小程序项目（逗号分隔）
PROJECTS=legal-instructor,code-signing,lyue,zenme-pan
```

**如何修改配置**：

1. 直接编辑 `sync-config.ini` 文件
2. 或运行 `config-wizard.bat` 重新配置

## 🔧 常见问题

### Q1: 提示"项目路径不存在"

**A: 运行 `config-wizard.bat`，输入正确的项目路径**

```
例如：C:\Users\YourName\Documents\ninglawyer-miniapp
```

---

### Q2: 提示"微信开发者工具路径不存在"

**A: 运行 `config-wizard.bat`，输入正确的微信开发者工具路径**

常见的安装位置：
- `C:\Program Files (x86)\Tencent\微信web开发者工具\cli.bat`
- `C:\Program Files\Tencent\微信web开发者工具\cli.bat`
- `D:\Program Files (x86)\Tencent\微信web开发者工具\cli.bat`

---

### Q3: 微信开发者工具没有自动刷新

**A: 检查微信开发者工具路径是否正确**

1. 运行 `config-wizard.bat`
2. 验证配置时，确认显示 `[✓] 微信开发者工具路径存在`
3. 如果显示 `[✗]`，重新配置路径

**临时解决方案**：在微信开发者工具中按 `Ctrl+S` 手动刷新

---

### Q4: 如何停止实时监控？

**A: 按 `Ctrl+C`**

```
按 Ctrl+C 停止监控
^C
```

---

### Q5: 如何修改监控间隔？

**A: 编辑 `sync-config.ini` 文件**

```ini
[General]
# 修改为 60 秒
MONITOR_INTERVAL=60
```

或运行 `config-wizard.bat`，输入新的监控间隔。

## 💡 使用技巧

### 技巧 1：保持实时监控开启

在日常开发时，保持实时监控开启，这样：

- ✅ 团队成员提交代码后，您会自动获取最新代码
- ✅ 微信开发者工具会自动刷新
- ✅ 无需手动操作，提高开发效率

---

### 技巧 2：使用快速提交

修改代码后，使用快速提交功能：

```
运行 start.bat → 选择 [5]
```

这样可以快速提交代码，节省时间。

---

### 技巧 3：自定义监控的小程序

如果只想刷新特定的小程序，编辑 `sync-config.ini`：

```ini
[Projects]
# 只刷新 legal-instructor
PROJECTS=legal-instructor
```
