🚀 快速开始

1 克隆项目
git clone https://github.com/hegui2022/ninglawyer-miniapp.git
cd ninglawyer-miniapp
2 启动数据库服务

使用 Docker Compose 快速启动 PostgreSQL 和 Redis：

docker-compose up -d
3 启动后端服务

Linux/Mac:

./start.sh

Windows:

start.bat
4 配置小程序

打开微信开发者工具，导入小程序项目（例如：miniprogram/legal-instructor）

⚠️ 注意事项

  • 确保已安装 Docker（用于数据库）
  • 确保已安装 Python 3.8+
  • 确保已安装微信开发者工具
  • 首次运行需要安装依赖，可能需要几分钟
