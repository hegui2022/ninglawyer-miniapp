## 项目架构设计

### 前后端分离架构

```
┌─────────────────────────────────────────┐
│         微信小程序矩阵（前端）           │
│  ┌──────────┐  ┌──────────┐            │
│  │法律教官  │  │宁律师家族│            │
│  └──────────┘  └──────────┘            │
│  ┌──────────┐  ┌──────────┐            │
│  │码上签约  │  │  理约    │            │
│  └──────────┘  └──────────┘            │
│  ┌──────────┐  ┌──────────┐            │
│  │ 怎么判   │  │ 防风险   │            │
│  └──────────┘  └──────────┘            │
└─────────────────────────────────────────┘
              ↓ HTTPS API
┌─────────────────────────────────────────┐
│         后端服务（Flask + LangChain）   │
│  ┌──────────┐  ┌──────────┐            │
│  │API Routes│  │Master    │            │
│  │          │  │Agent     │            │
│  └──────────┘  └──────────┘            │
│  ┌──────────┐  ┌──────────┐            │
│  │Lawyer    │  │Skill     │            │
│  │Factory   │  │Engine    │            │
│  └──────────┘  └──────────┘            │
└─────────────────────────────────────────┘
              ↓
┌─────────────────────────────────────────┐
│            数据存储层                    │
│  ┌──────┐  ┌──────┐  ┌──────┐          │
│  │PostgreSQL│Milvus│  S3  │          │
│  └──────┘  └──────┘  └──────┘          │
└─────────────────────────────────────────┘
```

## 设计规范

### 1. UI 设计风格

- **采用微信企业微信设计风格**
- **配色方案**：
  - 主色：#07C160（微信绿）
  - 辅助色：#07C160（主色）、#FA9D3B（警告）、#FA5151（错误）
  - 文字色：#111111（主要）、#666666（次要）、#B2B2B2（占位）
  - 背景色：#FFFFFF（默认）、#F7F7F7（页面）
- **圆角**：8px（基础）、12px（大）
- **间距**：16px（基础）、24px（大）

### 2. 组件化开发

- **组件位置**：`components/`
- **组件命名**：kebab-case（短横线命名）
- **组件结构**：
  ```
  component-name/
    ├── component-name.js
    ├── component-name.wxml
    ├── component-name.wxss
    └── component-name.json
  ```

### 3. 代码规范

- **Python**：
  - 遵循 PEP 8 规范
  - 使用类型注解
  - 文档字符串
  
- **JavaScript**：
  - ES6+ 语法
  - 模块化开发
  - 组件化思维

### 4. 测试驱动

- **单元测试**：`tests/unit/`
- **集成测试**：`tests/integration/`
- **开发一个模块，测试一个模块**
