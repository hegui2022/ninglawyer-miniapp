# 图片资源说明

## 状态栏图标（18x18pt，即 36x36rpx）

需要准备以下图标：

1. **signal.png** - 手机信号图标
   - 尺寸：36x36rpx
   - 格式：PNG（透明背景）
   - 颜色：黑色

2. **wifi.png** - WiFi 信号图标
   - 尺寸：36x36rpx
   - 格式：PNG（透明背景）
   - 颜色：黑色

3. **battery.png** - 电池图标（满电状态）
   - 尺寸：36x36rpx
   - 格式：PNG（透明背景）
   - 颜色：黑色

## 品牌图标

4. **paw-blue.png** - 蓝色狗爪印图标
   - 尺寸：160x160rpx
   - 格式：PNG（透明背景）
   - 颜色：品牌蓝 (#4A90E2)
   - 风格：简洁、现代、专业

## 备选方案

如果暂时无法准备图标，可以使用以下临时方案：

1. 使用文字图标（emoji）：
   - 信号：📶
   - WiFi：📶
   - 电池：🔋
   - 狗爪印：🐾

2. 使用在线图标库：
   - Iconfont（阿里巴巴矢量图标库）
   - IconPark（字节跳动图标库）

## 图标获取建议

1. **品牌图标**：找设计师设计或使用在线图标生成工具
2. **状态栏图标**：可以从系统图标库获取，或使用开源图标库
3. **统一风格**：确保所有图标风格一致，使用相同的线条粗细和圆角
