## 📥 下载项目

### 方式一：通过 Git 克隆（推荐）

```bash
git clone https://github.com/hegui2022/ninglawyer-miniapp.git
cd ninglawyer-miniapp
```

### 方式二：直接下载 ZIP

1. 访问：https://github.com/hegui2022/ninglawyer-miniapp
2. 点击右上角 "Code" 按钮
3. 选择 "Download ZIP"
4. 解压到本地目录

## 🛠️ 测试环境准备

### 1. 安装微信开发者工具

**下载地址**：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

支持 Windows、macOS、Linux 系统。

### 2. 注册微信小程序账号

1. 访问：https://mp.weixin.qq.com/
2. 使用微信扫码登录
3. 点击"立即注册" → "小程序"
4. 填写邮箱、密码等信息完成注册
5. 邮箱验证后，进行主体信息登记（个人或企业）

### 3. 获取 AppID

注册成功后，在"开发" → "开发设置" 中获取 AppID。

**注意**：如果没有 AppID，可以使用测试号进行基础测试。

## 📝 注意事项

### 图片资源

当前项目使用网络图片作为占位符（https://via.placeholder.com），如果网络不通可能导致图片无法显示。

**解决方案**：
- 准备实际的图片资源
- 替换代码中的图片路径
- 建议图片尺寸：
  - 首页轮播图：750 x 400
  - 功能图标：128 x 128
  - 头像：200 x 200

### 本地存储

项目使用微信小程序本地存储（`wx.getStorageSync` / `wx.setStorageSync`）保存数据：
- 合同数据
- 用户信息
- 草稿数据

**注意**：本地存储在清除小程序缓存后会丢失。

### API 配置

当前项目主要使用本地数据，未配置真实的后端 API。如果需要对接后端：

1. 在 `app.js` 中配置 `globalData.config.apiUrl`
2. 替换 `wx.request` 调用为真实 API
3. 配置服务器域名（在小程序后台"开发" → "开发设置"）

### Canvas 签名功能

合同签署使用 Canvas 实现手写签名，需要确保：
- 微信开发者工具版本 >= 1.05.2107140
- 真机测试时注意兼容性

## 🐛 常见问题

### Q1: 页面显示空白

**可能原因**：
- 图片资源加载失败
- 数据格式错误

**解决方案**：
- 检查网络连接
- 查看控制台错误信息
- 检查 JSON 数据格式

### Q2: 点击按钮无响应

**可能原因**：
- 页面路径配置错误
- 方法未绑定

**解决方案**：
- 检查 `app.json` 中的页面注册
- 检查 `bindtap` 绑定的方法是否存在

### Q3: Canvas 签名无法绘制

**可能原因**：
- Canvas 上下文未正确初始化
- 触摸事件未正确绑定

**解决方案**：
- 检查 `onReady` 生命周期
- 检查 `bindtouchstart/move/end` 事件

### Q4: 导入项目时报错

**可能原因**：
- AppID 不正确
- 项目目录不完整

**解决方案**：
- 使用测试号或正确的 AppID
- 检查项目目录结构是否完整
