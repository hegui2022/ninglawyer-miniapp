# 宁律师智能法律咨询 Agent V5.0

基于豆包大语言模型、LangChain 和 LangGraph 框架构建的智能法律咨询 Agent，集成语音交互与知识库 RAG 能力，支持文本+语音同步输出。

## 核心功能

### 1. 法律咨询
- 支持多轮对话的自然语言法律咨询
- 基于知识库的精准回答（RAG）
- 语音输入与语音输出（豆包语音）

### 2. 合同起草助手 V5.0
采用多智能体架构，支持以下合同类型的智能起草：

- **标准劳动合同**：适用于全日制用工的正式劳动合同
- **非全日制用工合同**：适用于兼职、小时工等非全日制用工
- **实习协议**：适用于在校学生实习场景
- **退休返聘协议**：适用于退休人员返聘工作场景
- **项目制合同**：适用于项目承包、工程承揽等场景
- **劳务派遣合同**：适用于劳务派遣三方合作场景

### 合同导出功能
- 支持 Word 格式导出（.docx）
- 支持 PDF 格式导出（.pdf）

### 3. 合同审查功能 ✨ 新增
- **智能风险识别**：自动识别合同中的法律风险点
- **多维度检查**：基本信息、合同期限、劳动报酬、社会保险、合同解除等
- **风险等级评定**：高风险、中风险、低风险三级评估
- **详细审查报告**：生成包含问题描述、修改建议的完整报告
- **快速检查模式**：一键快速检查是否存在明显风险

### 4. 合同管理系统 ✨ 新增
- **合同保存**：将起草的合同保存到数据库
- **合同查询**：按类型、状态、时间等条件查询合同
- **合同更新**：修改已保存的合同内容和状态
- **版本控制**：支持创建合同新版本，保留历史记录
- **审查记录**：保存和管理合同审查记录

### 5. 附加条款 ✨ 新增
- **保密协议**：约定双方对商业秘密的保密义务
- **竞业限制**：限制离职后在竞争对手处工作
- **知识产权**：明确职务成果的知识产权归属
- **自定义条款**：根据双方特殊需求添加条款

## 微信小程序 V6.0 📱

### 功能概述
基于微信原生框架开发的移动端应用，完全克隆豆包风格 UI，支持文本/语音双模式交互，并与后端 API 服务深度集成。

### 核心页面

#### 1. 首页 (index)
- 对话聊天界面
- 文本输入 + 语音输入
- AI 智能回复
- 聊天历史记录

#### 2. 合同列表 (contract-list)
- 查看所有合同
- 筛选条件（全部/草稿/已签署）
- 查看审查状态
- 点击查看详情

#### 3. 合同详情 (contract-detail)
- 查看完整合同内容
- 查看审查结果概况
- 一键审查合同
- 跳转到审查详情页面

#### 4. 合同审查 (contract-review) ✨ 新增
- 审查概况（整体风险、风险统计）
- 分级风险详情（高/中/低风险）
- 风险描述与修改建议
- 免责声明
- 跳转到编辑页面

#### 5. 合同编辑 (contract-edit) ✨ 新增
- 完整的合同编辑表单
- 基础信息编辑（合同名称、甲乙方）
- 关键条款编辑（期限、试用期、工作内容、薪资等）
- 社保公积金开关
- 附加条款配置（保密、竞业限制、知识产权、自定义）
- 备注说明
- 保存与取消操作

#### 6. 合同起草 (contract-draft)
- 六种合同类型选择
- 智能引导式输入
- 实时参数展示
- 一键生成并保存

### 技术特性
- **RESTful API 集成**：通过 Flask 后端 API 实现数据交互
- **Token 认证**：支持用户身份验证
- **统一请求封装**：app.js 封装 request 方法
- **优雅的 UI/UX**：豆包风格，流畅交互
- **数据同步**：与后端数据库实时同步

### 配置说明
- API 地址：`http://localhost:5001/api`
- Token 存储：本地缓存（wx.setStorageSync）
- Tab 页：首页、合同、起草

## 技术栈

- **模型**：doubao-seed-1-8-251228 (豆包 Agent 优化版)
- **框架**：LangChain, LangGraph
- **语音**：豆包语音 (TTS/ASR)
- **知识库**：coze-coding-dev-sdk Knowledge
- **存储**：PostgreSQL 数据库, S3 对象存储
- **测试服务**：Flask (用于模拟对话界面)
- **移动端**：微信小程序原生框架
- **合同起草**：多智能体架构（Master Agent + Scenario Agents + Skill Agents）
- **文档生成**：python-docx, reportlab (PDF)
