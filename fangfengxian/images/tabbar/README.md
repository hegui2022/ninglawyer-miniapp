# TabBar 图标说明

## 图标要求
- **尺寸**: 81px * 81px
- **格式**: PNG
- **颜色**:
  - 未选中：灰色 (#999999)
  - 选中：绿色 (#4CAF50)

## 需要的图标
1. **义务** (obligation)
   - 未选中：`obligation.png`
   - 选中：`obligation-active.png`
   - 建议：卷轴、文档或法律图标

2. **管理** (manage)
   - 未选中：`manage.png`
   - 选中：`manage-active.png`
   - 建议：齿轮、设置或文档图标

3. **发现** (discover)
   - 未选中：`discover.png`
   - 选中：`discover-active.png`
   - 建议：放大镜、指南针或探索图标

4. **我的** (profile)
   - 未选中：`profile.png`
   - 选中：`profile-active.png`
   - 建议：用户、头像或个人资料图标

## 占位说明
当前使用占位图标，请替换为实际的设计图标。

## 创建方法
1. 使用设计工具（如 Figma、Sketch、Photoshop）创建图标
2. 导出为 PNG 格式，尺寸 81x81 像素
3. 将图标文件放置在 `images/tabbar/` 目录下
4. 重命名为对应的文件名
