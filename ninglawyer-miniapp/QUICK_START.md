# 快速开始 - 宁律师小程序

## 🚀 5 分钟快速上手

### 第一步：启动自动同步工具

1. 双击运行 `start.bat`
2. 选择 `[1] 启动实时监控`
3. 保持这个窗口运行，它会自动监控代码更新

### 第二步：打开微信开发者工具

1. 打开微信开发者工具
2. 导入 `legal-instructor` 项目
3. 在小程序页面按 `Ctrl + S` 重新编译

### 第三步：开始开发

正常开发，当监控工具提示有更新时：
- 按 `Ctrl + C` 停止监控
- 双击运行 `sync.bat` 同步代码
- 在微信开发者工具中按 `Ctrl + S` 刷新
- 重新启动监控

## 📋 日常开发工作流

```
启动监控 → 开发代码 → 发现更新 → 同步代码 → 刷新项目 → 继续开发
```

### 详细步骤

1. **每天早上启动监控**
   ```
   双击 start.bat → 选择 [1]
   ```

2. **正常开发**
   - 在微信开发者工具中编写代码
   - 监控窗口会每 30 秒检查一次更新

3. **发现更新时**
   - 监控窗口会显示：`[发现更新] X 个新提交`
   - 按 `Ctrl + C` 停止监控

4. **同步代码**
   ```
   双击 sync.bat
   ```

5. **刷新项目**
   - 在微信开发者工具中按 `Ctrl + S`
   - 或点击"编译"按钮

6. **继续开发**
   - 重新启动监控：`双击 start.bat → 选择 [1]`

## 💡 提高效率的技巧

### 1. 分屏显示

将监控窗口放在屏幕一侧，不影响您的工作：

```
┌─────────────────┬─────────────────────┐
│   监控窗口      │  微信开发者工具     │
│   (常驻后台)    │  (主要工作区)       │
│                 │                     │
│  [发现更新]...  │  正常开发...        │
│                 │                     │
└─────────────────┴─────────────────────┘
```

### 2. 设置自动同步

编辑 `monitor.py`，设置 `'auto_sync': True`：

```python
CONFIG = {
    'project_path': 'C:\\Users\\Administrator\\ninglawyer-miniapp',
    'monitor_interval': 30,  # 监控间隔（秒）
    'auto_sync': True,  # 自动同步（改为 True）
}
```

这样就不需要手动运行 `sync.bat` 了！

### 3. 创建快捷键

为 `sync.bat` 创建桌面快捷键，设置快捷键如 `Ctrl + Alt + S`，一键同步。

## 🔧 常见问题

### Q1: 监控工具不工作？

**A**：检查以下内容：
1. 是否在正确的目录下运行
2. Git 是否正确安装（运行 `git --version` 测试）
3. 网络连接是否正常

### Q2: 如何修改监控间隔？

**A**：编辑 `monitor.py` 中的配置：

```python
'monitor_interval': 60,  # 改为您想要的秒数
```

### Q3: 微信开发者工具路径错误？

**A**：在 `auto-sync.bat` 中修改：

```batch
set WECHAT_TOOLS_EXE="您的路径\cli.bat"
```

### Q4: 如何查看更新历史？

**A**：双击 `start.bat`，选择 `[3] 查看最近提交记录`
