### 方案二：混合方案（人工录制 + 合成语音）

**适用场景**：想用自己的声音，但不想全部人工录制

#### 实现方式
1. **重要回复用你的声音**：
   - 你录制关键法律意见的音频
   - 上传到对象存储
   - Agent 检测到重要回复时，优先使用你的录音

2. **日常回复用合成语音**：
   - 普通问答继续使用 TTS 合成
   - 选择最接近你声音的预置音色

#### 优点
- 核心内容用真声，更有说服力
- 日常回复自动化，节省时间
- 可以根据场景灵活切换

#### 需要做什么
1. 录制常见法律问题的回复（如：欠款纠纷、劳动合同、离婚流程等）
2. 上传到对象存储
3. 我帮你实现智能切换逻辑

---

### 方案三：第三方声音克隆服务（高级）

**适用场景**：必须使用 AI 克隆你的声音

#### 实现步骤
1. **选择声音克隆服务**：
   - ElevenLabs（国际知名，中文支持一般）
   - 阿里云智能语音（支持中文声音克隆）
   - 腾讯云语音合成（支持个性化音色）
   
2. **声音克隆流程**：
   - 提供 1-3 分钟你的录音样本
   - 上传到声音克隆平台训练
   - 获取克隆音色的 API
   - 集成到宁律师 Agent

#### 优点
- 真正的 AI 声音克隆
- 无需录制每条回复

#### 缺点
- 需要第三方服务（可能付费）
- 集成复杂度较高
- 声音克隆效果可能需要多次调整

---

## 🎤 立即开始

### 推荐步骤

1. **先试听方案一的样音**
   - 打开 `assets/voice_samples/` 目录
   - 逐个试听，找到最接近你声音的
   
2. **决定使用哪种方案**
   - 如果预置音色接近 → 选择方案一（最快）
   - 如果想用真声录制 → 选择方案二（混合方案）
   - 如果必须 AI 克隆 → 选择方案三（高级）

3. **告诉我你的选择**
   ```
   "我想用【小天】音色" 
   或
   "我想用混合方案，帮我录制几条关键回复"
   或
   "我要声音克隆，帮我集成 ElevenLabs"
   ```

---

## 📝 注意事项

1. **音色选择**：律师人设建议选择成熟稳重的音色（云州、大一、优雅男士）
2. **录制质量**：如果使用混合方案，录制时请选择安静环境，使用高质量麦克风
3. **合规性**：确保你有使用自己声音的授权，不要使用他人声音
