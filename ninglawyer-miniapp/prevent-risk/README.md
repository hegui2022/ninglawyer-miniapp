# 防风险小程序

## 概述

防风险小程序是宁律师法律咨询小程序矩阵的重要组成部分，专注于企业风险管理和防控，提供风险扫描、合规检查、风险预警等功能。

## 功能特点

### 1. 首页
- 风险概览展示
- 快捷功能入口
- 最近扫描记录
- 风险提示信息
- 一键扫描入口

### 2. 风险扫描
- 多种扫描类型选择
  - 合同合规检查
  - 企业资质审查
  - 法律风险评估
  - 合规性检查
- 灵活的扫描范围设置
- 实时扫描进度显示
- 详细的扫描结果展示
- 风险列表和等级分类

### 3. 风险报告
- 综合风险分析报告
- 风险趋势图表
- 风险分类统计
- 详细风险列表
- 改进建议
- 报告导出和分享

### 4. 合规检查
- 多种合规检查类型
  - 合同合规
  - 企业合规
  - 劳动合规
  - 税务合规
- 合规要求清单
- 通过/未通过状态
- 详细的失败原因
- 改进建议

### 5. 风险预警
- 实时预警提醒
- 三级预警分类
  - 紧急预警（红色）
  - 重要预警（黄色）
  - 一般预警（蓝色）
- 预警处理功能
- 预警设置
  - 开启/关闭通知
  - 声音提醒
  - 震动提醒

## 使用说明

### 开始使用

1. 在微信开发者工具中打开 `prevent-risk` 目录
2. 配置小程序 AppID
3. 配置后端 API 地址（utils/config.js）
4. 编译运行

### 主要功能使用

#### 风险扫描
1. 进入"风险扫描"页面
2. 选择扫描类型
3. 设置扫描范围和选项
4. 点击"开始扫描"
5. 查看扫描结果

#### 查看报告
1. 进入"风险报告"页面
2. 查看风险概览和趋势
3. 浏览详细风险列表
4. 查看改进建议
5. 导出或分享报告

#### 合规检查
1. 进入"合规检查"页面
2. 选择检查类型
3. 查看合规要求清单
4. 查看未通过项和建议
5. 点击"开始检查"

#### 风险预警
1. 进入"风险预警"页面
2. 查看预警概览
3. 浏览预警列表
4. 处理预警信息
5. 配置预警设置
